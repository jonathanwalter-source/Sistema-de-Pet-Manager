## 🚀 Sobre o Projeto
O **PetManager** nasceu para resolver a dor de cabeça diária de gerenciar agendamentos de banho, tosa, consultas e o controle de estoque em pet shops, tudo em uma interface web responsiva e rápida.

## ✨ Funcionalidades
* Cadastro completo de tutores e pets.
* Agendamento inteligente de serviços (banho, tosa, consultas).
* Envio automático de lembretes por e-mail (24h antes).
* Controle de estoque em tempo real com alertas de nível mínimo.

## ⚙️ Pré-requisitos Técnicos
Antes de começar, certifique-se de ter instalado em sua máquina:
* Python 3.11 ou superior
* Gerenciador de pacotes `pip`
* PostgreSQL rodando localmente ou via container Docker
